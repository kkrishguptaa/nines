# Nines Reliability Compiler Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Ship a Python reliability compiler (`nines.run`) that synthesizes an independent verifier, fans out diverse solvers, escalates until a Wilson lower bound clears a declared `target` (or a `budget` stops it), and demos lift vs single-shot Claude with an inspectable receipt.

**Architecture:** Verifier-first orchestration: synthesize a checker from the task alone, canary it on known-bad output, then run diverse solver attempts through that checker only. Honest statistics (Wilson interval) drive escalation; one public seam (`nines.run`) is the acceptance surface. Demo comparison harness wraps the same seam.

**Tech Stack:** Python 3.11+, `anthropic` SDK (Claude), `hypothesis` (property tests), `asyncio` + semaphore, `pytest`, subprocess sandbox with timeouts. Optional thin Streamlit/FastAPI demo UI only after the core loop works.

**Tracker map:** PRD #1 · scaffold #2 · verifier #3 · fan-out #4 · Wilson/escalate #5 · comparison #6 · harden #7

## Global Constraints

- Product name: **Nines** (positioning: reliability compiler).
- Python-only task surface for v1.
- Primary test seam: `nines.run(task, *, target, budget) -> Receipt` — prefer this seam; do not proliferate internal seams.
- Verifier never receives solver reasoning — only candidate output.
- `target_met` iff Wilson lower bound ≥ `target`.
- Zero passing candidates ⇒ never silent best-guess; return failure detail + `target_met: false`.
- Subprocess sandbox only — README must state unsafe for untrusted input.
- No persistence; no durable execution; no eval dashboard.
- Submission claims must map to real code; label mocks as mocks.
- Cut order if behind: P1 features → escalation (fixed N) → receipt UI (JSON). Never cut verifier synthesis or gating.

- [ ] **Step 3: Implement Wilson + escalate in `run`**

```python
# Pseudocode for run loop after verifier OK
batch = diversity_configs(initial_n)
while True:
    for config in batch:
        if budget_exhausted: break
        output, cost = solve_once(...)
        ok = check_output(meta, output)
        record attempt; accumulate cost
    low, high = wilson_interval(passes, trials)
    receipt.wilson_low, receipt.wilson_high = low, high
    if low >= target:
        receipt.target_met = True; break
    if budget_exhausted:
        receipt.target_met = False; break
    batch = diversity_configs(next_batch_size)  # escalate
```
